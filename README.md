# 要谈一场硬话之前，先把这场谈话设计出来

说一句「我要跟老板谈加薪，准备了两次都没敢开口」，它不会甩给你一段话术。

它先出一张图，把这场谈话拆成四层；再问你最多四个问题；然后给你一份设计：分几个阶段谈、对面最可能的三种反应你各说什么、哪三句话不能出口。

> 不是替你去说，是让你在开口之前，已经想过对面会怎么接。

`不用编程` · `不用注册` · `不上传` · `不收费` · `装完就能用` · MIT

急着装？直接跳到 [怎么装](#怎么装)。

## 为什么做这个

AI 越来越快了。模型一天比一天聪明，agent 一秒能跑几十步。

但那场谈话没变：加薪你拖了半年，离婚你提了三次又咽回去，跟合伙人拆伙你连开场句都没想好。

难的不是「不会说话」。是这些话一出口就收不回——说重了关系断了，说轻了对方不当真，说错了还会变成对方手里的证据。

市面上的东西给的都是话术：几段式、几个步骤、一句「你可以这么说」，拿走就完了。真到了现场，对面一句反问，你手上没有第二句。

所以我把这件事做成了过程：八步。前三步连着给完，第 4 步起一步一停，每一步等你拍板。谈完它还回来问你结果。

底下的料是书：方法池九条（非暴力沟通、关键对话、高难度谈话、掌控谈话、修复尝试、课题分离……每条都写了"什么时候它会失效"），案例库十七个原案、跨九本书，都映射到八步的哪一步用。

它不以书为骨架。入口永远是你这场谈话卡在哪一步，书是被这一步临时叫来的原料。

## 你会得到什么

不是一段话，是四样东西：

| 时间 | 会发生什么 |
|---|---|
| 第一次聊完 | 一张四层地图（局面／目标／结构／话术）＋一句判断：能谈、只能谈一半、还是现在不该谈 |
| 同一轮里 | 目标重设：这次谈完你能拿到什么、拿不到什么，说清了你才往下走 |
| 第 4 步 | 一张分段时间表：四到六段，每段多少分钟、要拿到什么 |
| 第 6 步 | 三到五张应对卡：对面最可能的反应，各配一句你说的话＋一条边界 |
| 第 7 步 | 红线：三句不能说、三件不能做，谈前划死 |
| 谈完 | 它按你定的时间回来问你三句，落一张案例卡（存在你自己电脑上） |

走完你手上是：**一张图、一份分段时间表、几张应对卡、一张红线清单，外加一个「谈完它会来找你」的约定。**

它不承诺你谈得成。这一点写在免责里，不藏在末尾。

## 你可以直接说这句

装好之后随便挑一句，改成你自己的情况发过去：

- 「我要跟老板谈加薪，憋了半年，两次都到门口又回去了。」
- 「我要跟合伙人拆伙，想把条件谈清楚，但不想撕破脸。」
- 「我想跟我老婆谈离婚，怕一开口就变成吵架。」
- 「客户要压价 15%，我得谈回去，又不能把这单丢了。」
- 「我妈又开始催婚，这次我想把话说到底，又不想吵翻。」

它不会问「你的目标是什么」，也不会先给你一段开场白。

它先问你最多四个问题，能做成选项的都做成选项，剩下推出来的标一句「这是我的假设」。这四个答案不齐，它下面给的东西全是错的，所以它不肯跳过。

## 它不解决什么

- **替你做决定。** 要不要离婚、要不要辞职，它只设计怎么谈，不替你定谈不谈。
- **法律结论。** 「他这算不算违约」「能不能仲裁」，它给事实和时限，然后让你去找专业意见。
- **心理状态。** 「我一跟人说话就发抖」不是谈话设计能解决的，这类它不接。
- **管住对面。** 对方不接、继续装死、反手告状，都可能发生。设计只管你这一侧不失分。
- **一句话的小活。** 催文件、回投诉、回一句阴阳——它不接，会直接告诉你这是表达问题、不是设计问题。

边界说清楚，比多承诺一条功能有用。

## 它怎么管住你

八步，一步一停。不是给你一段开场白就结束。

| 步 | 它干的事 | 说人话就是 |
|---|---|---|
| 1 出图 | 把这场谈话拆成四层，画成一张图，标出你哪几步要拍板 | 先让你看见整场，不然你连自己怕什么都说不清 |
| 2 补缺口 | 最多四个问题，能给选项的都给成选项，推出来的标「假设」 | 它不问你想怎样，先问这场的边界在哪 |
| 3 判断与目标 | 三个判断选一个：能谈／只能谈一半／现在不该谈；再当场跟你对目标 | 目标对不上，它不许你往下走 |
| 4 谈话框架 | 四到六段：阶段、时长、目的、核心一句 | 谈多久、每段要拿到什么，先排好 |
| 5 材料与准备 | 两类清单：手上要有、场外要办 | 只告诉你准备什么，不查岗 |
| 6 反应与应对 | 三到五张应对卡，按概率排，最可能的第一条 | 对面会怎么接，你手上已经有三句话 |
| 7 红线与注意 | 三句不能说、三件不能做、安全预案 | 把止点划死，谈崩了也不越界 |
| 8 定时与回访 | 定两个时间，到点自动回来问你三句，落一张案例卡 | 谈话什么时候进行、什么时候复盘，第二个更重要 |

前三步连着给完，不让你喊「继续」。第 4 步起每步结束都停住，等你自己开口。

五道门一路卡着：是不是真该用（四条判据里满足两条）、目标一致了没有、该停的停了没有、红线越没越、回访落了没有。

## 它见过的情况

三种方向加一类判局：

| 方向 | 它接得住的话 |
|---|---|
| 向上 · 对面有权力差 | 加薪 · 面试谈 offer · 辞职面谈 · 报一个重大坏消息 · 要资源要编制 |
| 对外 · 谈判与交易 | 合作条件 · 续约涨价 · 供应商施压 · 危机对质 |
| 对内 · 家庭与亲密 | 离婚与分居 · 重大财产怎么分 · 跟原生家庭划边界 · 育儿路线摊牌 |
| 判局 · 第 2、3 步用 | 这场到底该不该谈 · 对面的决定权在不在他手上 · 该先找谁 |

十七个原案都在 `references/07-cases.md` 里，每个都标了"用在八步的哪一步"。比如「橙子姐妹——各拿一半是双输」那条，用在第 3、4 步：裁决切成两半看着最公平，可一个要果肉、一个要皮——各让一步之前，先确认两边要的是不是同一部分。

> 红线那三条要在前面说清：它不设计威胁、羞辱、人身攻击、违法违规的内容，你要求也不设计；不伪造身份和证据；不阴阳怪气。设计是为了让对方听懂并回应，不是为了让他难受又抓不到把柄。

## 它说话长什么样

下面是包里第 6、7 步的真实样本（场景是分居摊牌），一字未改，只截了两张应对卡和一条红线清单。

先说第 6 步——把对面最可能的反应，变成你手上现成的话：

> 第 6 步，反应与应对。这一步只做一件事：把对面最可能的三种反应，变成你手上三句现成的话。
>
> 一、挽留型：她哭，说「我改，你别走」
> 你说：我知道你难受，但我的决定不变。今天先说你今晚住哪、接下来怎么走。
> 边界：不接「改」字。一接，决定重新打开，后面全乱。
>
> 二、施压型：她拿娘家压你，「我爸妈不会同意」
> 你说：那是你和你爸妈的事，我不参与。你要我怎么配合，我配合。
> 边界：只背「性格不合」，不背事实性坏名声。
>
> 补库的事只有你能做：
> · 除了这三种，你还怕她有哪种反应？

（第三张卡是危机型：对方威胁自伤时，它不让继续谈——给三个动作，打 120、打电话给家人、你离开现场，并写明「你是当事人，不是救援者」。）

第 7 步收口是这样，把止点划死：

> 第 7 步，红线与注意。这一步只做一件事：把止点划死——不管她怎么反应，下面这些不越。
>
> 一、三句不能说
> 1、「我早就想离了」——会引爆「你骗我这么多年」。
> 2、任何具体金额——今晚报数，告知决定就变成讨价还价。
> 3、任何人身攻击——既伤人，也会变成对方手里的证据。
>
> 二、三件不能做
> 1、不当场签任何协议或欠条。
> 2、当晚不同处一室。
> 3、不在深夜谈，不喝酒谈。

**它不会做的几件事：**

- 不先给你一段开场白。第一步永远是图，不是话术。
- 不在你没答完四个缺口之前下判断。
- 不一次把八步全发给你。第 4 步起一步一停，这是规矩不是风格。
- 不替你决定分手、辞职、断绝关系。它只给路径和后果。
- 不设计威胁、羞辱、伪造。你要求也不设计。

## 怎么装

### 方式一 · 不打开终端，四步（大部分人用这个）

1. 在这一页找到绿色的 **`Code`** 按钮 → 点 **`Download ZIP`**。
2. 解压。解压出来的文件夹可能叫 `how-to-talk-main`，**把它改名成 `how-to-talk`**（这步别省，名字不对就认不出来）。
3. 随便打开一个文件夹窗口，把下面这行**粘进最上面的地址栏**，按回车：

   ```
   C:\Users\你的名字\.workbuddy\skills
   ```

   把 `你的名字` 换成你自己的 Windows 用户名。macOS / Linux 用 `~/.workbuddy/skills`。

4. 把改名后的 `how-to-talk` 整个文件夹拖进去，重启 WorkBuddy。

然后说一句「我要跟老板谈加薪，帮我设计一下」，它就接上了。

> **看不到 `.workbuddy` 是正常的**——它是隐藏文件夹。不用去改「显示隐藏文件」的设置，把路径粘进地址栏就能直接进去。
>
> 解压后多出来的 `README.md`、`TESTS.md`、`CHANGELOG.md` 不影响使用，不用删。

### 方式二 · 什么都不装（装不上就走这条）

没有 WorkBuddy、或者懒得动文件夹，也能用。

打开仓库里的 `SKILL.md`，全选复制，粘进任何 AI 的对话框，末尾加一句：

> 按这个八步协议陪我设计一场谈话：我要跟合伙人拆伙，想把条件谈清楚。

纯文字，不用插件、不用账号。**它退了半步，但主干还在**——八步顺序、五道门、三条红线都写在 `SKILL.md` 里。少的是 `references/` 那九份细则：方法池的失效条件、十七个案例、四层地图的画法，这些没一起粘过去，它就只能给主干，给不出案例对照。

### 方式三 · 一行命令（给习惯终端的人）

```bash
git clone https://github.com/TomatoRibs/how-to-talk.git ~/.workbuddy/skills/how-to-talk
```

## 你现在用的方式，换成它会不一样在哪

| 你现在用的 | 它不一样的地方 |
|---|---|
| 网上搜来的「高情商话术」「三句话搞定」 | 那些是一次答完，你拿走就没了。它八步走完，中间三次停下来等你拍板。 |
| 沟通课、非暴力沟通这类书 | 书讲原理，读完你还得自己翻译成本场的话。它把原理直接落成你这场谈话的第几句话。 |
| 语音对练 App、口才训练 | 练的是表达。它设计的是这一场具体谈话，谈完还按时间回来问你结果。 |
| 找朋友商量 | 朋友给你立场和情绪。它给你对面最可能的三种反应，和每种的接法。 |
| 硬着头皮上，谈完后悔 | 它要求你在开口前把红线划死：哪三句不能说、哪三件不能做。 |

最根本的区别只有一件事：**别人给你一段话，它给你一整场的过程，还管到谈完之后。**

## 你的数据在哪

- 每次谈完落的案例卡，写在你自己的工作目录：`<你的工作目录>/谈话案例/YYYY-MM-DD-场景.md`，不写进这个包。
- 包里两个脚本零网络请求，不需要账号；你自己的谈话内容不经过这个包上传到任何地方。
- 你要谈什么、说了什么，只存在你和你在用的那个 AI 之间。这个包本身不记录你。

## 免责声明

这不是法律意见，也不是心理诊断。涉及合同、仲裁、监护、财产分割的具体结论，请找专业意见；涉及持续的情绪问题、自伤风险，请走专业路径——它在谈话设计里遇到这类信号会停下来，不往下设计。

它也管不了对面：对方不接、装死、反手告状，都可能发生。底下的方法池有书有据，但「按这套设计谈就一定拿到结果」这句话它不承诺，也承诺不了。
